This is a sample post, written in plain Markdown. Delete it and write your own.

To publish a new post:

1. Create a file in `_posts/` named like `2026-11-20-my-title.md`
2. Give it a title in the front matter above (the bit between the `---` lines)
3. Write below in Markdown, commit, and push — GitHub builds it automatically within about a minute

It will appear at `/blog/` and in the RSS feed at `/feed.xml`, styled with the same black background and Inter font as the rest of the site.
